Install

GitHub Releases publish dbadminer for Linux, macOS, and Windows on amd64 and arm64.

  1. Download the archive for your system from Releases.
  2. Unpack it and put the binary on your PATH.
  3. Point it at a database and open the UI.
dbadminer --dsn 'postgres://user:pass@127.0.0.1:5432/app?sslmode=disable'

Or leave --dsn empty and export DATABASE_URL (or another supported variable). Then open http://127.0.0.1:8080. The binary listens on 127.0.0.1:8080.

dbadminer --version

From a checkout

go run ./cmd/dbadminer
