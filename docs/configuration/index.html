Configuration

Access mode

Read-only mode allows one SELECT, WITH, EXPLAIN, VALUES, TABLE, or SHOW. Write statements are rejected before they reach the database. PostgreSQL, MySQL, and MariaDB also run those statements in a read-only transaction. SQLite opens with mode=ro.

Full access runs one statement with the database user's privileges, including DML and DDL.

dbadminer --access=full
dbadminer --readonly=false
DBADMINER_ACCESS=full

--access takes readonly or full. Set only one of --access and --readonly. Write UIs stay hidden in read-only mode and their APIs return 403.

Library and CLI flags

Flags accepted by Flags and Run: --addr, --access, --readonly, --user, --password, --max-rows, --query-timeout, --max-body, --max-response.

cmd/dbadminer also accepts --dsn, --db-host, --db-port, --db-user, --db-password, --db-name, and --schema. DBADMINER_DATABASES names more than one database; each name prefixes those variables.

--user and --password are basic auth for the page. They are never taken from the database password. Config.Schema hides every other schema for a pool you already opened.

Limits

Row page size is capped by MaxRows. Request bodies, query time, and encoded response size are also capped. Prefer tighter limits when the explorer is shared across a team VPN.
