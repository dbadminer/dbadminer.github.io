Dialects

DBAdminer ships with PostgreSQL, MySQL / MariaDB, and SQLite support. Dialect detection runs from the driver name and connection metadata. Custom databases can implement the Dialect interface.

Built-in

DialectNotes
PostgreSQLSchema-aware listing, search_path when --schema is set, read-only transactions in read-only mode.
MySQL / MariaDBSchema maps to database name; read-only transactions in read-only mode.
SQLiteFile path or sqlite:// DSN. Opens with mode=ro while the explorer is read-only.

Extending

Implement Dialect: Name, Quote, TablesQuery, ColumnsQuery, ColumnsArgs, Qualify, SupportsReadOnlyTx. Planned additions for richer schema views include index and foreign key queries, DDL, dialect-specific pagination, and placeholders for filters.

Tested versions and contribution notes are in the repository. Features should work on all three dialects or be clearly marked as dialect-specific.
