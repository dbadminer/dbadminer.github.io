CLI

The standalone binary resolves a DSN from flags and environment variables, then serves the explorer UI.

Resolution order

  1. --dsn
  2. DATABASE_URL, otherwise DATABASE_PRIVATE_URL
  3. One of POSTGRES_URL, POSTGRESQL_URL, MYSQL_URL, MYSQL_DSN, SQLITE_URL
  4. libpq PG* when PGDATABASE is set (PGHOST, PGPORT, PGUSER, PGPASSWORD, PGSSLMODE)
  5. Docker Postgres POSTGRES_* when POSTGRES_DB is set
  6. MYSQL_* when MYSQL_DATABASE is set
  7. Generic DB_* when DB_NAME or DB_DATABASE is set
  8. SQLITE_PATH, otherwise SQLITE_DATABASE

SQLite opens with mode=ro while the explorer is read-only. A missing host or port becomes localhost and 5432 or 3306.

Field overrides

These fields override the chosen Postgres or MySQL URL, including --dsn and DATABASE_URL. A flag wins over the matching variable. SQLite ignores host, port, user, password, and database name.

FieldFlagVariable
Host--db-hostDB_HOST
Port--db-portDB_PORT
User--db-userDB_USER, otherwise DB_USERNAME
Password--db-passwordDB_PASSWORD
Database--db-nameDB_NAME, otherwise DB_DATABASE
Schema--schemaDB_SCHEMA
dbadminer \
  --dsn 'postgres://postgres:5432/app?sslmode=disable' \
  --db-user ada \
  --db-password 'p@ss' \
  --schema public

--schema limits the table list to that schema. On PostgreSQL it also sets search_path. --user and --password are basic auth for the page, not the database.
