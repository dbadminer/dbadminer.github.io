Security

DBAdminer is a local window onto a database you already have. It is not a sandbox and it is not safe to expose on a public network.

What the library does

  • Listens on a loopback address by default. 0.0.0.0 and :: are accepted so a container can receive connections that Docker forwards. A specific public address is refused.
  • Rejects requests whose Host is not loopback. A request Origin, when present, must match that host.
  • Defaults to read-only access; write statements are rejected before they reach the driver.
  • Accepts schema, table, and order names only when they match a live catalog entry, then quotes them. Query values are bound parameters.
  • Compares basic-auth credentials in constant time and slows repeated failures.
  • Sets Content-Security-Policy, X-Content-Type-Options, and Referrer-Policy.
  • Caps request bodies, row counts, query time, and encoded response size.
  • Renders values in the UI with textContent.

What you should do

  • Create a database user with SELECT only when you want read-only browsing.
  • Open SQLite with mode=ro (the CLI does this in read-only mode).
  • Publish the Docker port on host loopback only: -p 127.0.0.1:8080:8080.
  • Set --user and --password if the page itself should require a login. Database passwords are never used as page credentials.

Report vulnerabilities privately to the repository maintainers. Full notes live in SECURITY.md.
