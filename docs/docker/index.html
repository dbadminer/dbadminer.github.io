Docker

Version tags (v*) publish dbadminer/dbadminer for that version and for latest. Publish the port only on the host loopback.

docker pull dbadminer/dbadminer:latest
docker run --rm -p 127.0.0.1:8080:8080 \
  -e DATABASE_URL='postgres://postgres:5432/app?sslmode=disable' \
  -e DB_USER=ada \
  -e DB_PASSWORD='p@ss' \
  -e DB_SCHEMA=public \
  dbadminer/dbadminer:latest

Open http://127.0.0.1:8080. The image starts read-only.

docker run --rm -p 127.0.0.1:8080:8080 \
  -e DBADMINER_ACCESS=full \
  -e DATABASE_URL='postgres://...' \
  dbadminer/dbadminer:latest

Multiple databases

Set DBADMINER_DATABASES to a comma-separated list of names. Each name is a prefix: SHOP_DATABASE_URL is read as DATABASE_URL, and SHOP_DB_PASSWORD is read as DB_PASSWORD.

services:
  dbadminer:
    image: dbadminer/dbadminer:latest
    ports:
      - "127.0.0.1:8080:8080"
    environment:
      DBADMINER_DATABASES: shop,app
      SHOP_DATABASE_URL: mysql://mysql:3306/shop
      SHOP_DB_USER: ada
      SHOP_DB_PASSWORD: secret
      APP_DATABASE_URL: postgres://postgres:5432/app?sslmode=disable
      APP_DB_USER: ada
      APP_DB_PASSWORD: secret
      APP_DB_SCHEMA: public

Demo stack

docker compose -f examples/demo/compose.yaml up --build

Open http://127.0.0.1:8090 for the demo app and http://127.0.0.1:8080 for DBAdminer.
