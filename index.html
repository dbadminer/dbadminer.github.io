DBAdminer

Browse PostgreSQL, MySQL, MariaDB, and SQLite without leaving your stack.

Starts read-only. Ship a binary, embed next to a *sql.DB, or pull the Docker image. The library imports only the Go standard library. Listed on the MariaDB Ecohub.

Install Docs GitHub

Drop it into Compose

Publish only on loopback, point env vars at your services, and open http://127.0.0.1:8080. Multi-database names become a switcher in the UI.

Full Docker guide · Demo stack

services:
  dbadminer:
    image: dbadminer/dbadminer:latest
    ports:
      - "127.0.0.1:8080:8080"
    environment:
      DBADMINER_DATABASES: shop,app
      SHOP_DATABASE_URL: mysql://mysql:3306/shop
      SHOP_DB_USER: ada
      SHOP_DB_PASSWORD: secret
      APP_DATABASE_URL: postgres://postgres:5432/app?sslmode=disable
      APP_DB_USER: ada
      APP_DB_PASSWORD: secret
      APP_DB_SCHEMA: public
